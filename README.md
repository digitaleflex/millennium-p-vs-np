# Millennium P vs NP Research Lab

Open research laboratory for a rigorous study of the P vs NP problem through theoretical computer science, computational experiments, formal reasoning, and AI-assisted research.

## Core principle

We do not assume P = NP or P ≠ NP. Computational evidence is not a proof of a universal complexity-theoretic claim. AI-generated arguments require independent verification.

## Research lifecycle

Question → Definition → Prior Work → Hypothesis → Test → Observation → Analysis → Proof/Refutation → Review → Result.

## Architecture

- `docs/` — foundations, complexity theory, P vs NP, NP-completeness, barriers and literature.
- `research/` — questions, hypotheses, conjectures, lemmas, proofs, counterexamples and results.
- `experiments/` — reproducible computational investigations.
- `src/` — research software.
- `tests/` — software and mathematical tests.
- `formal/` — future formal verification.
- `ai/` — AI-assisted research agents and protocols.
- `datasets/` — experiment data and metadata.
- `journal/` — chronological research record.
- `templates/` — standardized scientific artifacts.
- `scripts/` — validation, benchmarking and reproducibility.
