# Research Protocol

## Claim lifecycle

IDEA → HYPOTHESIS → TEST → OBSERVATION → ANALYSIS → PROOF/REFUTATION → REVIEW → RESULT

## Required fields

Every substantial research artifact should identify the question, definitions, assumptions, prior results, claim, methodology, evidence, counterexamples, limitations, verification status and reproducibility information.

## Review gates

1. Logical consistency.
2. Definition check.
3. Prior-art check.
4. Counterexample check.
5. Barrier check.
6. Independent verification.
7. Reproducibility.

## Evidence taxonomy

- KNOWN
- DEFINITION
- HYPOTHESIS
- EXPERIMENT
- OBSERVATION
- CONJECTURE
- LEMMA
- PROOF
- COUNTEREXAMPLE
- RESULT
