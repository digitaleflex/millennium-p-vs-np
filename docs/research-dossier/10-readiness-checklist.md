# 10 — Checklist de préparation

## Mathématiques
- [ ] Ensembles et fonctions compris.
- [ ] Quantificateurs compris.
- [ ] Preuve directe comprise.
- [ ] Contradiction comprise.
- [ ] Induction comprise.
- [ ] Contre-exemple compris.
- [ ] Big-O compris.

## Informatique
- [ ] Je sais expliquer un algorithme.
- [ ] Je sais analyser son coût.
- [ ] Je comprends les graphes.
- [ ] Je peux programmer une expérience simple.

## Complexité
- [ ] Je peux définir P.
- [ ] Je peux définir NP.
- [ ] Je comprends certificat et vérification.
- [ ] Je comprends une réduction polynomiale.
- [ ] Je sais ce que signifie NP-complet.
- [ ] Je comprends le rôle de SAT.

## Méthodologie
- [ ] Je distingue observation et preuve.
- [ ] Je cherche activement les contre-exemples.
- [ ] Je documente mes hypothèses.
- [ ] Je vérifie les sources.
- [ ] Je conserve mes échecs.
- [ ] Je peux expliquer exactement ce que je n'ai pas démontré.

## Question finale

Qu'est-ce que je sais ?
Qu'est-ce que je suppose ?
Qu'est-ce que j'ai testé ?
Qu'est-ce que je n'ai pas encore démontré ?
