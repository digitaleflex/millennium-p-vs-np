# 03 — Théorie de la complexité

## Question centrale

Nous étudions les ressources nécessaires pour résoudre des problèmes computationnels.

## Taille d'entrée

Une entrée possède une taille n selon une convention explicitement définie.

## Complexité temporelle

On étudie comment le nombre d'opérations croît avec n : O(1), O(log n), O(n), O(n log n), O(n²), O(n³), O(2^n), O(n!).

## Asymptotique

La question théorique est comment le coût évolue lorsque la taille de l'entrée tend vers l'infini, pas seulement le nombre de secondes sur une machine donnée.

## Décision vs optimisation

P vs NP est formulé autour des problèmes de décision. « Existe-t-il une solution dont le coût est ≤ K ? » est différent de « Quelle est la meilleure solution ? »

## Algorithme vs heuristique

Une heuristique peut être excellente en pratique sans fournir de garantie polynomiale pour toutes les instances.

## Complexité pratique vs théorique

Un algorithme polynomial peut être impraticable ; un algorithme exponentiel peut fonctionner sur de petites instances. Ces questions ne doivent pas être confondues.
