# 01 — Méthodologie de recherche scientifique

## Une recherche commence par une question

Mauvais départ : « Je vais prouver P ≠ NP. »

Meilleur départ : « Quelles propriétés connues des problèmes NP-complets pourraient être pertinentes pour une nouvelle approche de borne inférieure ? »

Puis : « Quelle affirmation minimale puis-je tester ou démontrer ? »

## Séparer les niveaux de connaissance

- **Fait établi** — résultat vérifiable.
- **Définition** — convention mathématique précise.
- **Observation** — comportement constaté dans une expérience.
- **Hypothèse** — explication proposée qui pourrait être fausse.
- **Conjecture** — énoncé mathématique encore non démontré.
- **Lemme** — résultat intermédiaire.
- **Preuve** — démonstration logique complète.
- **Contre-exemple** — objet qui réfute une affirmation universelle.

## Cycle scientifique

Question → état de l'art → définition → hypothèse → prédiction → test → observation → analyse → preuve/réfutation → vérification indépendante → résultat.

## Falsification

Pour chaque hypothèse, demander : « Qu'est-ce qui me ferait abandonner cette hypothèse ? »

## Recherche documentaire

Pour chaque source : identifier l'auteur, la publication et la date ; lire l'énoncé exact ; distinguer le résultat de son interprétation ; conserver la référence ; vérifier les conditions du théorème.

## Anti-biais

Avant de chercher à confirmer une idée : chercher un contre-exemple, chercher des travaux contradictoires, demander une critique indépendante et rechercher les techniques connues qui rendent l'approche difficile.

## Échec

Un raisonnement réfuté doit être conservé s'il permet de comprendre où l'argument échoue, quelle hypothèse était trop forte et quelle nouvelle question apparaît.
