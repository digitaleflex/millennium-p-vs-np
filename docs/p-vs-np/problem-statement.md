# P vs NP — Problem Statement

## P

P is the class of decision problems solvable by a deterministic Turing machine in polynomial time.

## NP

NP is the class of decision problems for which a proposed certificate can be verified by a deterministic Turing machine in polynomial time.

## Fundamental inclusion

P ⊆ NP.

The open question is whether P = NP or P ≠ NP.

## Important distinctions

- decision vs optimization;
- deterministic vs nondeterministic computation;
- asymptotic complexity vs practical performance;
- exact algorithms vs heuristics;
- empirical evidence vs mathematical proof.

A fast implementation on many inputs cannot establish P = NP. A slow implementation cannot establish P ≠ NP.
