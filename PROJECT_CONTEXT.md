# Project Context

## Origin

This project follows a serious exploration of whether it is possible to work systematically on a Millennium Prize Problem, with P vs NP selected as the first target.

## Current posture

This is a research laboratory, not a claim that a solution has been found.

The project combines human-directed research, theoretical computer science, reproducible computation, formal reasoning and AI-assisted research.

## AI collaboration rules

The AI assistant may explain concepts, generate candidate hypotheses, propose experiments, inspect arguments and organize literature. It is not the final mathematical authority. Important claims must be independently verified.

## Non-negotiable rules

1. Never present intuition as a theorem.
2. Never present an experiment as a proof.
3. Never call an idea novel before checking prior work.
4. Search for counterexamples before strengthening a claim.
5. Record failed approaches.
6. State assumptions explicitly.
7. Independently verify important proofs.
8. Preserve provenance for research results.

## First objective

Build enough mathematical and complexity-theoretic foundations to understand exactly what a valid P vs NP result would require.
